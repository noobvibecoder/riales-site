Politica de privacidad

Esta pagina explica que datos usa RIALES, para que se usan y como podes solicitar eliminacion de datos.

Responsable y contacto

RIALES es responsable de esta app. Para temas de privacidad, escribinos a contacto@riales.app.

Datos que recopilamos

  • Datos de cuenta, como email e identificador de usuario.
  • Datos financieros que ingresas: ingresos, gastos, categorias, deudas, pagos, calendario, activos y efectivo disponible.
  • Preferencias necesarias para mostrar y sincronizar la app.
  • Archivos que seleccionas voluntariamente para importar datos o restaurar respaldos.

Si usas registro por voz, la app puede pedir permiso de microfono. RIALES no guarda grabaciones de audio.

Uso de los datos

Usamos tus datos para crear y proteger tu cuenta, guardar tu informacion financiera, mostrar resumen, calendario, registros, deudas, activos, indicadores y respaldos, y mantener la seguridad del servicio.

RIALES no vende tus datos personales ni financieros.

Almacenamiento y seguridad

Los datos se guardan bajo controles de acceso por usuario. La app tambien puede guardar una copia local cifrada o temporal en tu dispositivo para funcionamiento y respaldo.

RIALES usa comunicacion segura y almacenamiento protegido para las sesiones locales.

Eliminacion de cuenta y datos

Podes solicitar la eliminacion de tu cuenta y datos asociados desde riales.app/eliminacion-cuenta o desde la app.

Cambios

Podemos actualizar esta politica cuando cambie la app, la infraestructura o los requisitos legales. La version vigente sera la publicada en esta URL.
